Dudas generales sobre funcionamiento, acceso y datos registrados

¿Cómo funciona la app?

Navegación por módulos

Usa la barra lateral izquierda (7 módulos desbloqueados). Panorama muestra el mapa y KPIs por territorio; Reconstrucción el avance físico-financiero; Ejes 5 ejes estratégicos; Territorios tabla comparativa; Mapas capas dedicadas; Documentos repositorio; Reportes generador. El header cambia título/descripción según el módulo (currentModule).

Filtros y territorio

Arriba: Fecha de corte y Ámbito (General/Urbano/Rural) escalan todos los números vía globalFactor = fechaMult * ambitoMult. Abajo: Buscador (departamento/municipio/zona) + chips región/subregión/tipo. El breadcrumb y level-toggle permiten subir/bajar de nivel (Colombia → Depto → Municipio). Todo es local y reactivo.

Mapa y KPIs

Leaflet + CARTO/Esri. Cada círculo es un territorio con color por severidad ( Muy alto → Muy bajo). Clic navega. Los 4 hero-stats y los KPI tiles se escalan con scaleKpis(share). El Panel Admin edita esos shares en vivo.

Excel / PDF automático

Botón Exportar (topbar) → Excel (clic) con 6 hojas (Resumen, Economía, Financiación, Ranking, Departamentos, Documentos) vía XLSX + PDF (clic derecho) vía jsPDF con datos vivos. También en Reconstrucción, Territorios y Reportes.

¿Quién ha entrado? — Datos reales

Cada login real se guarda en localStorage.altis_access_log con email, nombre, rol, territorio, IP mock 190.x.x.x, fechaLocal, modulo. Abre ALTIS-Admin → Usuarios & Roles y verás la tabla con accesos reales (agrupados por email, último acceso, IP) + `Ver historial` (últimos 8). Si está vacío, muestra demos en Sin acceso. También se replica en altis_audit.

Datos registrados

¿Dónde viven los datos?

Todo es localStorage (sin backend):
• altis_db_v2 — KPIs nacionales, economía, funding, Top5, municipios/zonas, fechas.
• altis_docs_v2 — 7 evidencias semilla + las que cargues (base64) con estado validado/pendiente.
• altis_access_log — logins reales.
• altis_audit — trazabilidad de cambios.
• altis_theme — claro/oscuro.
El Panel Admin edita altis_db_v2 y el Panorama reacciona vía storage event.

Documentos y evidencias — investigación

Cada doc tiene tipo, título, descripción, territorio, autor, estado, tags, coords, archivo base64. Filtra por texto/tipo/estado/territorio, arrastra archivos al drop zone, abre modal para Validar/Rechazar/Eliminar/Descargar y Ver en mapa (centra leafletMap2). El botón Investigar genera stats automáticas (validadas %, fotos/dron, cobertura).

¿Cómo editar y exportar?

En Admin → General/Economía/Territorios/Fechas mueve sliders o inputs y pulsa Guardar cambios → se guarda en altis_db_v2 y el Panorama se actualiza al instante. Usa Exportar JSON o Excel/PDF en cualquier módulo para descargar el corte actual. El tema claro/oscuro y el logo superior izquierda son persistentes.

Tratamiento de datos personales — Ley 1581 de 2012

Responsable: Observatorio Nacional de Reconstrucción — ALTIS.

Finalidad: Autenticación, trazabilidad de accesos (altis_access_log / altis_audit), gestión de cuentas (altis_accounts) y personalización por territorio. Los datos se almacenan localmente en tu navegador (localStorage) para esta demo.

Derechos: Conocer, actualizar, rectificar y suprimir tus datos. Escríbenos a soporte@altis.gov.co (demo).

Autorización: Al marcar la casilla aceptas de forma libre e informada el tratamiento conforme a la Ley 1581 y Decreto 1377 de 2013.

Puedes revocar la autorización borrando el localStorage o desde el Panel de Datos.
